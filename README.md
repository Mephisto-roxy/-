# 学习通 AI 实践 · 对话助手（CDP 版）使用说明

## 文件清单
- 启动调试Edge.bat —— 启动带调试端口的 Edge（独立配置目录，不影响平时浏览器；扫码登录一次长期有效）
- cdp-chat.js —— 核心脚本（纯 Node 实现，零依赖）
- 启动对话助手.bat —— 一键入口（自动找 Node：PATH 没有就用 DSH 自带的）

## 快速开始
1. 双击 启动对话助手.bat
   （若调试 Edge 没在运行，脚本会自动启动它；首次需要在弹出的窗口里扫码登录学习通）
2. 看到「情景 / 任务说明 / 对话记录」和「回复>」提示符后，直接打字 = 以小林身份发送
3. 发送后脚本自动等待 AI 回复并打印到终端
4. 满意后输入 /eval 结束练习并评分

## 交互命令
    /r        重读当前对话
    /task     查看任务说明
    /score    查询情景 / 成绩 / 次数 / 登录态
    /eval     点击「结束练习并评估」并等待真实分数（0 是评分中占位符，脚本会等到非 0）
    /restart  点击「重新练习」重开一轮
    /quit     退出

## 全自动模式（可选：接你自己的 LLM Key）
在命令行设置环境变量后再运行：
    set CHAT_LLM_KEY=sk-xxxx
    set CHAT_LLM_API=https://api.deepseek.com/chat/completions
    set CHAT_LLM_MODEL=deepseek-chat
    set CHAT_AUTO_ROUNDS=5
    启动对话助手.bat --auto
说明：对方（AI 角色）的消息作为 user，小林的历史回复作为 assistant，交给 LLM 续写下一条。
加 CHAT_AUTO_EVAL=1 会在轮数结束后自动点击「结束并评分」。

## 高分小抄（今日三个情景 97/97/94 的实战经验）
- 开场先复述双方观点、再给折中方案（展示倾听）
- 方案要有「人 / 事 / 时间」三要素（展示执行力）
- 主动把话题引向自我觉察：自己更享受什么、驱动力是什么（测评类情景的得分核心）
- 每次评估报告的「不足」部分就是下一轮的写作提纲
- 收尾要致谢 + 总结收获
- 该课程的情景是轮换的（杨善林 / 职业测评 / 伦理思辩），进入对话先 /task 确认自己在哪个情景

## 常见问题
- 端口 9222 连不上 → 先运行 启动调试Edge.bat，或直接用 启动对话助手.bat（会自动拉起）
- 页面空白 / 次数显示 0 → 数据偶发加载失败，/restart 或刷新几次即可
- 成绩显示 0 → 评分中的占位符，稍等或 /score 再查
- 需要 Node 21+（内置 WebSocket/fetch）；启动器已内置 DSH 自带 Node 的兜底路径
