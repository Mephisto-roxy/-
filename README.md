# 学习通 AI 实践 · 情景对话助手（CDP 版）

一个**零依赖、纯本地**的小工具：通过 Chrome DevTools 协议接管一个带调试端口的 Edge 窗口，
自动完成学习通「AI 实践」情景对话的**读取、发送、等待回复、结束评分、成绩查询**——
你只需要决定「说什么」。

```
┌──────────┐   终端输入/命令    ┌──────────────────┐   CDP(9222)   ┌──────────────┐
│   你      │ ───────────────▶ │  cdp-chat.js     │ ────────────▶ │ 调试版 Edge   │
│ (大脑)    │ ◀─────────────── │  (机械操作)       │ ◀──────────── │ (已登录学习通) │
└──────────┘   打印对方的回复   └──────────────────┘   读DOM/发消息 └──────────────┘
```

## 特性

- **纯本地、零依赖**：不需要安装任何 npm 包，默认不调用任何第三方 API（不花钱）
- **自动读**：任务说明、情景类型、历史对话、登录态、剩余次数一屏打尽
- **自动等**：发送后自动检测「AI 已生成完毕」再打印，不会截断半句话
- **自动评分**：`/eval` 点击「结束练习并评估」并等待真实成绩（自动跳过评分中的 0 占位符）
- **可选全自动**：`--auto` 接入任意 OpenAI 兼容 LLM Key（默认关闭，不设 Key 绝不联网调用）

## 环境要求

- Windows + Microsoft Edge
- Node.js 21+（仓库零依赖；不想装 Node 可从 Releases 下载**已捆绑运行时**的开箱即用 zip）

## 快速开始（三步）

**① 配置你的作业链接（推荐，可跳过）**

双击 `设置作业链接.bat`，粘贴你自己的情景对话页面链接。
找法：平时浏览器登录学习通 → 课程 → 点开老师布置的 AI 实践任务 → 打开对话页 → 复制地址栏整串。
也可以完全跳过，之后在弹出的浏览器里手动打开作业页。

**② 启动**

双击 `启动对话助手.bat`：会弹出一个独立配置的 Edge 窗口（与你平时的浏览器互不影响），
第一次需要扫码/账号登录学习通，登录态之后长期有效。

**③ 对话**

黑窗口显示情景与任务说明后，**直接打字 = 发送**；发送后自动等待对方回复；
聊满意后输入 `/eval` 结束练习并评分。

## 交互命令

    /r        重读当前对话
    /task     查看任务说明
    /score    查询情景 / 成绩 / 次数 / 登录态
    /eval     点击「结束练习并评估」并等待真实分数
    /restart  点击「重新练习」重开一轮
    /url      查看配置的作业链接
    /help     帮助        /quit  退出

## 全自动模式（可选：接你自己的 API）

想让脚本自动写回复？接入你自己的 LLM Key——**完全可选**，不配置就是手动模式，零费用。

**方式一（推荐）**：双击 `配置AI接口.bat` → 菜单选服务商（DeepSeek / 智谱GLM / OpenAI / 自定义 OpenAI 兼容接口）→ 粘贴你的 Key → 保存完成。

**方式二**：命令行环境变量

    set CHAT_LLM_KEY=sk-xxxx
    set CHAT_LLM_API=https://api.deepseek.com/chat/completions
    set CHAT_LLM_MODEL=deepseek-chat

然后运行：

    启动对话助手.bat --auto

说明：
- 对方（AI 角色）的消息作为 `user`、你的历史回复作为 `assistant` 交给 LLM 续写；
- `CHAT_AUTO_EVAL=1` 会在轮数结束后自动点击「结束并评分」；
- 配置保存在 `llm-config.txt`，**已被 .gitignore 忽略、永远不会被提交**；Key 属于你个人，请勿外传；
- 不配置 Key 时，脚本不会发起任何第三方请求。

## 工作原理（为什么需要「调试版 Edge」）

1. 正常的 Edge 出于安全不允许程序远程控制网页；`--remote-debugging-port=9222` 会开放本机调试端口（CDP 协议）；
2. 调试实例使用独立的 `--user-data-dir`，和你日常浏览器互不影响；
3. 脚本通过 `127.0.0.1:9222` 用 WebSocket 与页面通信：`Runtime.evaluate` 读 DOM、`Input.insertText` 注入文字、
   DOM 点击「发送 / 结束练习并评估」按钮——**整个过程不碰键盘鼠标，也不需要管理员权限**；
4. 「AI 生成完毕」的判定：每 5 秒读一次最新气泡，连续两次内容不变即认为完成。

## FAQ

- **双击 .bat 被蓝色 SmartScreen 拦截**：点「更多信息」→「仍要运行」（脚本无签名导致的正常提醒）
- **找不到 Node**：安装 Node 21+，或使用 Releases 里的开箱即用包（自带 node.exe）
- **页面空白 / 次数显示 0**：平台数据偶发加载失败，`/restart` 或刷新几次
- **成绩显示 0**：评分中的占位符，稍等或 `/score` 再查
- **同一课程多个情景轮换**：进入后先 `/task` 确认当前情景
